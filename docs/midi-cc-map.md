# 默认 MIDI 映射

## 音符
- Note On/Off（默认接收全部通道，可用 `synth_set_channel_filter()` 收窄）
- Velocity 1–127 → 音量/亮度；**velocity 0 视为 Note Off**
- Pitch Bend → ±2 半音（`SYNTH_BEND_SEMITONES` 可改）

## CC 映射
| CC | 功能 | 说明 |
|---|---|---|
| 1 | 调制轮 → LFO 深度 | 0..127 → 0..+1（叠加在音色值上） |
| 2 | 滤波器截止（粗） | −0.25..+1.25 倍频程 |
| 5 | 滑音时间 | 直接改当前音色副本 |
| 7 | 主音量 | 0..127 |
| **20** | **琶音器模式** | 0=关, 1=上行, 2=下行, 3=上下, 4=随机, 5=按演奏顺序 |
| **21** | **琶音器速率** | 0.5 … 30 步/秒（指数） |
| **22** | **琶音器门限** | 0..127 → 0.05..1.0 |
| **23** | **琶音器八度范围** | 1 … 4 |
| 64 | 延音踏板 | ≥64 开 |
| 65 | 单音（连奏）模式 | ≥64 开 |
| 71 | 共振 | |
| 72 / 73 | 放大器 起音 / 释音 | |
| 74 | 滤波器截止（细） | −0.5..+1.5 倍频程（常用旋钮） |
| 76 / 77 | LFO 速率 / 深度 | |
| 79 | 音色音量 | |
| 91 / 93 | 合唱 / 延迟 混合 | 阶段 2 起支持实时覆盖（当前由音色决定） |
| 120 | All Sound Off | 立即静音 |
| 121 | Reset All Controllers | 复位 CC 状态 |
| 123 | All Notes Off | 释放所有音 |

## Program Change
- Bank Select MSB(CC0)/LSB(CC32) + Program Change(PC) 选择音色（当前只用 PC）。
- 若 SD 卡的 `/synth` 下存在 `NNN.syn`（NNN = 3 位音色号）则由 port 层加载，否则用内置音色表。
- 文本格式见 `docs/patch-format.md`。

## 其它
- 实时字节（0xF8 MIDI 时钟等）穿插安全；**0xF8 会驱动琶音器同步**（24 ppqn，默认 1/16 步 = 每 6 个时钟一步）。
- SysEx 阶段 1 直接丢弃并计数（`synth_stats_t.sysex_dropped`），阶段 2 用于 `.syx` 音色注入。
- 未识别 CC：忽略并计数（`synth_stats_t.unknown_cc`）。
