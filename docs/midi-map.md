# MIDI 映射表（音色号 / CC / NRPN）

板子在 Windows 里显示为 **`H750 PCM5102A Synth`**（USB-MIDI 类兼容设备，免驱；在 PowerShell 里通常是 `midiOut` 的第 **1** 号设备）。支持 16 个 MIDI 通道，音符 0–127，弯音 ±2 半音。

> 本文档对应固件：`Synth/src/core/engine.cpp`、`Synth/src/core/patch.cpp`、`Synth/include/synth/patch.h`。
> 代码改了这里也要跟着改；诊断读数用 `tools\status.ps1`，发消息用 `tools\play.ps1`。

---

## 1. 音色（Program Change，`0xC0 | 通道`）

Program Change **只影响发送它的那个通道**。16 个通道各自记住自己的音色号。

### 1.1 内置音色：PC 0–14（15 个，定义在 `Synth/src/core/patch.cpp:35`）

| ID | 名字 | 引擎 | 一句话 |
|---:|------|------|--------|
| 0 | Init Saw | 模拟 | 两路锯齿，默认音色（开机就是它） |
| 1 | Warm Pad | 模拟 | 慢起音 + 失谐，铺底 Pad |
| 2 | Bright Lead | 模拟 | 亮、衰减快，主音 |
| 3 | Sub Bass | 模拟 | 低八度正弦叠加，贝斯 |
| 4 | Pluck | 模拟 | 短促拨弦 |
| 5 | Square Keys | 模拟 | 方波键盘 |
| 6 | Super Saw | 模拟 | 多锯齿，宽 |
| 7 | Sine Flute | 模拟 | 正弦，长笛感 |
| 8 | PWM Strings | 模拟 | 脉宽调制的弦乐 |
| 9 | Res Sweep | 模拟 | 高共振 + 包络扫频 |
| 10 | Noise Sweep | 模拟 | 噪声 + 滤波扫频 |
| 11 | Organ | 模拟 | 风琴 |
| 12 | FM E.Piano | FM（DX7） | 电钢琴 |
| 13 | FM Bass | FM（DX7） | 贝斯 |
| 14 | FM Bell | FM（DX7） | 钟/铃 |

- **PC 15–19 没有内容**：会记下请求（`chan_idx`），但声音保持原样。
- 每个音色的完整参数（两个振荡器、滤波、两个包络、LFO、效果、音量）见 `patch.cpp:37` 起每行 `PATCH_FIELDS(...)`，列顺序注释在 `patch.cpp:36`。

### 1.2 QSPI 采样库：PC 20–23（来自 SD 上的 `samples.bin`）

| PC | 名字 | 采样来源 | 区数 | 循环 | 说明 |
|---:|------|----------|-----:|:----:|------|
| 20 | Piano | UprightPianoKW（Kawai 立式） | 13 | 否 | 每 3 个半音一个采样，3 秒 + 淡出 |
| 21 | Strings | VSCO 2 CE 小提琴组颤音持续音 | 6 | 是 | 铺底用，键区 G2–D5 |
| 22 | Bass | VSCO 2 CE 低音提琴持续音 | 7 | 是 | E0–G#2 |
| 23 | Perc | VSCO 2 CE 打击乐单发音 | 8 | 否 | 鼓组，键位见下表 |

**鼓组键位（PC 23）**

| 键 | 音色 | 键 | 音色 |
|---:|------|---:|------|
| 36 | 大鼓 | 44 | 牛铃 |
| 38 | 军鼓 | 45 | 低音桶鼓 |
| 39 | 响板 | 46 | 铃鼓 |
| 42 | 沙锤（当闭镲） | 48 | 高音桶鼓 |

> 打包时配了 10 个槽，但固件每件乐器最多 **8 个区**（`Synth/include/synth/sample.h:12`），所以 49 吊镲 / 51 叮叮镲 没有载入。

### 1.3 卡上自定义：PC 任意（000–999）

| 文件 | 内容 | 解析器 |
|------|------|--------|
| `/synth/NNN.syn` | 文本音色（`key = value`） | `Synth/src/app/patch_text.cpp:101` |
| `/synth/NNN.ins` | 采样乐器（指向 WAV/QSPI 采样） | `Synth/src/app/instrument_text.cpp` |

- `NNN` 就是 PC 号（三位十进制，例如 PC 5 → `/synth/005.syn`）。
- **加载优先级：QSPI 采样库 > `.ins` > `.syn` > 内置音色**（`Synth/port/patch_storage_sd.c:86`）。
- 加载发生在**主循环**（`synth_port_patch_service()`），不在音频中断里；没插卡/没文件时保持原音色不变。
- 卡上已有 `000.syn … 014.syn`（内置音色的文本版，改文件比重编译快；重启或重发 PC 生效）。
- 开机恢复：`/synth/state.cfg` 记录每个通道的音色号，改动后静默 2 秒自动保存。

### 1.4 多音色的边界

- 内置 15 个音色：**真正的每通道独立**（每个声部渲染时带自己的音色快照）。
- FM（PC 12–14）和采样库（PC 20–23）：引擎**只有一个实例**，所以是"**最后一次 PC 生效**"，两个不同 FM/采样音色的通道会互相抢。
- 全局效果链（合唱/延迟/过载）只有一条，跟随最近一次切换的音色。

## 2. CC 表（`0xB0 | 通道`）

### 2.1 演奏类（全局实时，影响所有通道）

| CC | 功能 | 值域 |
|---:|------|------|
| 1 | LFO 调制深度 | 0–127 → 0…1 |
| 2 | 亮度 / 截止（粗调） | 0–127 → −0.25…1.25 |
| 74 | 亮度 / 截止（宽范围） | 0–127 → −0.5…1.5 |
| 71 | 共振 | 0–127 → 0…1.5 |
| 11 | 总音量（表情） | 0–127 → 0…1 |
| 64 | 延音踏板 | ≥64 开，<64 松开（松开会释放被延音的音） |
| 65 | 单音模式 | ≥64 开 |
| 120 | 静音（所有音符立即停） | — |
| 121 | 复位控制器 | — |
| 123 | 全部音符关 | — |
| 弯音（`0xE0`） | 音高 ±2 半音 | 14 位，中心 8192 |

### 2.2 音色类（写"该通道的音色"，正在响的音立即跟随）

| CC | 功能 | 值域 |
|---:|------|------|
| 5 | 滑音时间 | 0–127 |
| 7 | 通道音量 | 0–127 |
| 79 | 音量（与 CC7 等效，GM 兼容） | 0–127 |
| 72 | 音量包络 attack | 0–127 |
| 73 | 音量包络 release | 0–127 |
| 76 | LFO 速率 | 0–127 |
| 77 | LFO 深度 | 0–127 |
| 91 | 延迟量（"混响"位置） | 0–127 |
| 93 | 合唱量 | 0–127 |
| 0 / 32 | Bank Select：**忽略**（本机只有一个音库） | — |

### 2.3 NRPN 选择（标准 4 条 CC）

| CC | 功能 |
|---:|------|
| 99 | 参数号 MSB（本机参数号 0–32 ⇒ 恒为 0） |
| 98 | 参数号 LSB（= 参数号） |
| 6 | 数据 MSB（14 位值的高 7 位） |
| 38 | 数据 LSB（14 位值的低 7 位） |
| 100 / 101 | 取消 NRPN 选择（回到普通 CC 处理） |

发送顺序：`CC99=0 → CC98=参数号 → CC6=值高 7 位 → CC38=值低 7 位`。
例：给当前通道设亮度 = 100（0–127 档）→ 目标 `cutoff=100` ⇒ `v8=100` ⇒ `v14 = 100<<6 = 6400` ⇒ `CC6 = 6400>>7 = 50`、`CC38 = 6400 & 0x7F = 0`。

### 2.4 琶音器

| CC | 功能 | 值域 |
|---:|------|------|
| 20 | 模式 | 0 = 关，1 = 上行，2 = 下行，3 = 上下，4 = 随机，5 = 按演奏顺序 |
| 21 | 速率 | 0.5 × 30^(v/127) Hz，实际 0.5–15 Hz（内部再夹到 0.2–30） |
| 22 | Gate 长度 | 0…1（内部再夹到 0.05–1.0） |
| 23 | 八度范围 | 1 = 1 个八度 … 4 = 4 个八度 |

> MIDI 时钟字节 `0xF8`（24 ppqn）可以安全穿插在任意消息之间。默认**不启用**时钟同步，琶音器按 CC21 的自由速率走；要用时钟同步得在代码里调 `Arp::SetClockSync(true)`（目前没有对应 CC）。

## 3. NRPN 参数表（参数号 0–32）

值的三种换算（`v14` = 送进来的 14 位值 0–16383）：

- 0…255 的字段：`v8 = v14 >> 6`
- 带符号字段：`vs = v14 − 8192`（±8192）
- 0…1 的浮点：`v01 = v14 / 16383`
- 离散选择：`v14 / 系数`（系数见下表"范围"列，**取整会截掉高档位**）

| 参数号 | 目标 | 范围 / 换算 | 说明 |
|-------:|------|-------------|------|
| 0 | cutoff | 0–127 | 亮度（截止频率） |
| 1 | resonance | 0–127 | 共振 |
| 2 | filter_env_amt | `v8 − 128` → −128…127 | 滤波包络量（可负） |
| 3 | keytrack | 0–127 | 键跟踪 |
| 4 | lfo_rate | 0–127 | LFO 速率 |
| 5 | lfo_depth | 0–127 | LFO 深度 |
| 6 | amp_a | 0–127 | 音量包络 attack |
| 7 | amp_d | 0–127 | decay |
| 8 | amp_s | 0–127 | sustain |
| 9 | amp_r | 0–127 | release |
| 10 | osc2_semi | `vs*24/8192` → ±24 | 振荡器 2 半音 |
| 11 | osc2_detune | `vs/128` → ±64 | 振荡器 2 失谐（音分） |
| 12 | sub_level | 0–255 | 次振荡器电平 |
| 13 | noise_level | 0–255 | 噪声电平 |
| 14 | glide | 0–255 | 滑音时间 |
| 15 | fx_drive | 0–255 | 过载 |
| 16 | fx_chorus | 0–255 | 合唱 |
| 17 | fx_delay | 0–255 | 延迟 |
| 18 | fx_delay_fb | 0–255 | 延迟反馈 |
| 19 | volume | 0–255 | 通道音量（0–255 精度） |
| 20 | master_vol | `v01` 0…1 | **总音量（全局）** |
| 21 | osc1_pw + osc2_pw | 0–255 → 5%…95% | 两个振荡器的脉宽 |
| 22 | filter_type | `v14/2341` → 0…6，**实际 0–3** | 0 = LP12，1 = LP24，2 = BP12，3 = HP12；4–6 落进 `filter.h` 的 default 分支，等同于 LP12 |
| 23 | flt_a | 0–127 | 滤波包络 attack |
| 24 | flt_d | 0–127 | decay |
| 25 | flt_s | 0–127 | sustain |
| 26 | flt_r | 0–127 | release |
| 27 | osc1_level | 0–255 | 振荡器 1 电平 |
| 28 | osc2_level | 0–255 | 振荡器 2 电平 |
| 29 | osc1_model | `v14/5461` → 0…2 | 0 = SAW，1 = SQUARE，2 = PULSE（**3 TRI / 4 SINE / 5 SUPERSAW / 6 NOISE 用 NRPN 到不了**） |
| 30 | osc2_model | 同上 | 同上 |
| 31 | lfo_shape | `v14/3277` → 0…4，实际 0–3 | 0 = SINE，1 = TRI，2 = SQUARE，3 = 采样保持 |
| 32 | lfo_dest | `v14/5461` → 0…2 | 0 = 音高，1 = 滤波，2 = 音量（**3 = 脉宽 到不了**） |

- 表外参数号 → 只累加 `nrpn_unmapped`，不改任何东西。
- 每次生效后会把新参数推给该通道正在响的声部（听得见实时变化）。
- 离散参数（22 / 29 / 30 / 31 / 32）的系数是早先按"更大范围"写的，所以可选档位被截断；要完整档位只能改音色文件或用 CC/直接改 `patch.cpp`。

## 4. 排障：看板子收到了什么

| 字段 | 含义 | 位置 |
|------|------|------|
| `midi_rx_bytes` | 收到的字节总数（一字节不差地核对发送量） | `g_synth_midi_rx_bytes` |
| `unknown_cc` | 没被任何 case 接住的 CC 数 | `synth_stats_t` |
| `nrpn_used` | 命中映射表的 NRPN 次数 | 同上 |
| `nrpn_unmapped` | 参数号不在 0–32 的 NRPN 次数 | 同上 |
| `last_nrpn` | 最近一次 NRPN：`MSB<<24 | LSB<<16 | 14 位值` | 同上 |
| `chan_patch` | 每通道音色号（4 bit/通道，15 = 库外/未知） | `g_app_status` |

`tools\status.ps1` 会把这些解出来；`tools\play.ps1 -Patch N -Notes "60,64,67"` 可以直接发 PC 和音符。

## 6. 已知限制

1. **FM 与采样引擎各只有一个实例**：两个不同 FM（或采样）音色的通道会互相抢，最后切换的生效。
2. **每件采样乐器最多 8 个区**（`SYNTH_ROM_MAX_ZONES`）。
3. **PC 15–19 无内容**（请求会记下，声音不变）。
4. NRPN 22/29/30/31/32 的离散档位被系数截断（见上表）；其中 filter_type 送 4–6 会被当成 LP12，lfo_shape 送 4 落到 default。
5. 全局效果链只有一条；效果参数取"最近一次切换的音色"。
